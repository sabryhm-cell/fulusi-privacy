# سياسة خصوصية فلوسي

الصفحة دي منشورة على GitHub Pages، والرابط بتاعها هو اللي بيتحط في
Google Play Console في خانة **Privacy Policy URL**.

الريبو ده **عام عن قصد** — GitHub Pages المجانية بتشتغل من الريبوهات
العامة بس. مفيهوش أي كود من التطبيق؛ صفحة واحدة وبس، عشان كود فلوسي
يفضل خاص.

## تعديل السياسة

عدّل `index.html`، وحدّث تاريخ «آخر تحديث»، وبعدين:

```bash
git add -A && git commit -m "Update privacy policy" && git push
```

GitHub Pages بتنشر التعديل لوحدها في خلال دقيقة.
